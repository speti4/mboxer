# Benchmark 2026-10-17 — a 14 GB Gmail Takeout archive

Closes milestone M1 (index core): the real archive indexes, re-opens and answers body searches
within the roadmap targets. Numbers only; no message content is recorded here. Reproduce with

```powershell
cargo build --release
scripts\benchmark.ps1 -Mbox "<path to the .mbox>" -Repeat 5 -Out docs\benchmarks\<date>.md
```

## M1 targets vs measured

| Target (tasks/roadmap.md, task 003) | Measured | |
|---|---|---|
| index build in acceptable time | 125 s cold file cache (HDD-bound, 114 MB/s); 35 s warm cache (CPU-bound, 401 MB/s) | ✓ |
| re-open in under 1 s | 20 ms for the whole `mboxer index` process on a fresh index; 7 ms `MboxIndex::open` inside `search` | ✓ |
| body search in under 1 s | 0.5–0.8 ms per query, 86 085 messages, accent folding both ways (`szamla` = `számla` = 1137 hits) | ✓ |
| peak memory under 1 GB while building (task 003) | 314 MB | ✓ |
| index size | 129 MB, 0.95 % of the mbox | — |

Baselines from the earlier tasks on the same machine and file: the raw streaming scan without
indexing took 107 s at 104 MB peak working set (task 002); the first index build took 122 s at 314 MB
(task 003). Indexing therefore costs about 15 % on top of reading the file from the SATA HDD, and
the disk is the bottleneck: once the file is in the OS cache the same build runs in 35 s.

Two runs of the script produced the generated section below. The first (cold cache, right after
other work on the disk) measured the 125 s build time; the second, kept here, ran minutes later
with the file cached and is the one with the corrected phrase query (the first run's phrase row
had lost its quotes on the way to the exe and counted the two-word AND instead: 84 hits, not 7).
The search timings were the same in both runs. Open and search are measured inside one process
with the index files warm; a cold-cache open was not measured (Windows has no simple way to drop
the file cache), the fingerprint check reads about 3 MB of the mbox in 18 seeks, so a cold open
on the HDD is expected to stay well under a second.
