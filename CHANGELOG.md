## 0.1.0 — 2026-10-18

First release: a Windows 11 viewer for large Gmail Takeout mbox archives (tested on a 14 GB export). One portable exe, nothing to install.

**Getting started:** unzip `mboxer-0.1.0.zip` anywhere, read `usage.md`, start `mboxer.exe` and open your `.mbox`. The first open builds a sidecar full-text index next to the file (`.mboxer/`, or under `%LOCALAPPDATA%\mboxer\index\` when the folder is read-only); every later open reuses it. The exe is not code-signed, so SmartScreen asks once (*More info → Run anyway*).

**What is in it** (milestones M1 Index core, M2 Viewer MVP, M3 Comfort, all closed by this release):

- Streaming mbox parser and a one-time sidecar full-text index with accent folding (`szamla` finds `Számla`); a 100 000-message archive re-opens in well under a second and a body search answers at once
- Three-pane viewer: Gmail label tree with counts, virtualised message list (conversations or single messages), reader with HTML / Text / Source views; HTML is sanitized and rendered in a sandboxed iframe with no network access, remote images on request
- Gmail-style query syntax in the search field (`from:`, `to:`, `subject:`, `after:`, `before:`, `label:`, `has:attachment` / `-has:attachment`, quoted phrases) plus a filter panel
- Attachments: list, open, save
- Export a message as `.eml`, print or save as PDF
- Several mbox files open side by side, one active at a time; the open set is remembered
- Light / dark theme: *Auto* (follows Windows), *Light*, *Dark*
- `mboxer-cli` for scan / index / search from a terminal (developer tool, not in the zip; build from source)

**Known limits:** Windows 11 only (macOS is milestone M4); the index is rebuilt whole when the mbox changes.
