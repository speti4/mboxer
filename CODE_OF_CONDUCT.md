# Code of conduct

mboxer adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for the issues, pull requests, discussions and every other project space.

In short: be kind and constructive, assume good intent, and keep criticism about the work, never about the
person. Harassment, insults and personal attacks are not tolerated.

A project space where people talk about their mail calls for one more rule: never post someone else's
messages, addresses or personal details. A post that does will be edited or removed.

## Reporting

Report unacceptable behaviour to the maintainer (@speti4) through a
[private report](https://github.com/speti4/mboxer/security/advisories/new), or with GitHub's *Report
content* menu on the comment. Reports are handled confidentially. The maintainer decides on the consequences,
following the Covenant's enforcement guidelines, from a warning up to a permanent ban from the project.
