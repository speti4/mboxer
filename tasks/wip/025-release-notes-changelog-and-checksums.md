# 025 — Release notes and changelog from the task files, checksums and third-party licences

## Context

What: `CHANGELOG.md` generated per release from the `done/` task files (their H1 and milestone), by a mode of
`scripts/sync-issues.py` or a sibling script reading the same frontmatter, with the 0.1.0 section backfilled; the
release job takes its notes from it instead of `generate_release_notes`; a `SHA256SUMS.txt` next to the zip;
a `THIRD-PARTY-LICENSES.html` inside the zip generated by `cargo-about`.
Why: the v0.1.0 notes were written by hand because the generated ones were a bare "Full Changelog" line (no PRs);
the task files already hold the history, and the MIT / Apache crates inside the one exe require their notices.
Done when: a dry run of the release script (or a throwaway `-rc` tag, deleted afterwards) produces the notes,
the checksum file and the licence file.
Run as a task session under docs/git-workflow.md, in parallel with 035 and 032; no tag is pushed without the user.
