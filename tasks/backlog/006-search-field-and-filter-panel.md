# Search field and filter panel

What: One search field (Ctrl+F / Ctrl+K focus, results refresh while typing with debounce) plus a filter panel: date range, sender, label, has-attachment. Filters combine with the text query; hit terms are highlighted in the list.
Why: The main pain of mboxviewer is its Advanced Find; this is the feature the project exists for.
Done when: A user who knows no syntax finds a mail by a body word and a sender within three interactions, in under a second per keystroke.
