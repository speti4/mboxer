# Gmail labels and conversation threads

What: Read X-Gmail-Labels and X-GM-THRID from the Takeout headers: label tree in the folders pane with counts, label filter in search, conversation grouping in the list.
Why: The Takeout mbox carries Gmail structure for free; it makes a flat archive navigable.
Done when: Clicking a label narrows the list; a message with replies shows as one expandable conversation.
