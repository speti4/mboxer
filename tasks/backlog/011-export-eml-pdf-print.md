# Export a message: .eml, PDF, print

What: Save the selected message as .eml (raw bytes from the offset), print or export to PDF via WebView2's print pipeline.
Why: Handing a found mail to someone else is the second most common follow-up to a search.
Done when: A message exported as .eml opens in Outlook or Thunderbird; the PDF matches the reader rendering.
